# Express Starter
A minimal Express API with in-memory storage.

## Setup Instructions

### 1. Clone the repository
```
git clone https://github.com/KhalilKhunji/express-starter.git
cd express-starter
```
### 2. Install dependencies
```
npm install
```
### 3. Run server
```
npm run dev
```
### 4. Explore the code!
The rest is up to you - create CRUD based on another resource, implement database storage, authentication, etc.
